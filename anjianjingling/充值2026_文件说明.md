## 1. 文件关系

## 2. 主脚本概况

- 目标分辨率注释：`720x1280`。
- 脚本源码约 **14,648 行**，检测到 **85 个 Function/Sub**。
- 主要 App 包名：酷狗 `com.kugou.android`、夸克 `com.quark.browser`、支付宝 `com.eg.android.AlipayGphone`、Via `mark.via`。
- 启动时通过设备 ICCID 区分不同设备并映射为 `code`（例如 157/178/188/198/208/308）。
- 任务数据主要从本机 `127.0.0.1:5000` 服务获取，随后执行 Web 登录、查价、App 登录、充值、优惠券/活动、支付和结果回传。

### 外部脚本/插件依赖

主源码开头导入：`xd.luae`、`xdpub.mqle`、`zm.luae`、`shanhai.lua`、`sqlite3.lua`。这些文件不在本次 `.mqb` 的 5 个核心拆包文件中，因此迁移环境时必须确认按键精灵环境中仍能找到它们。

## 3. 运行主线

大致调用链：

1. 读取设备 ICCID，映射设备 `code`。
2. 调用本机 `/getTelData` 获取手机号、验证码、会员规格、订单 ID 等任务信息。
3. `order(oid)` 读取/补全订单信息并确定充值类型。
4. `web端登录()` → `web端价格()` 完成 Web 侧登录和价格探测。
5. `appdl()` 完成 App 登录。
6. `开通会员()` 根据规格分发到豪华/超级会员及对应时长处理函数。
7. 过程中可能进入生日券、3 天券、九元券、十五元券、抽奖/活动等分支。
8. 通过 `充值方式一/二/三`、`支付密码`、支付宝相关逻辑完成支付。
9. 使用 `status/statusa/ord_result/uporderid_status` 等向本机后端回传状态。
10. 收尾关闭相关 App，并 `RestartScript` 进入下一轮。

## 5. 本机后端接口依赖

源码中直接依赖 `http://127.0.0.1:5000`，至少包含以下接口：

- `GET /getTelData`：获取待处理任务。
- `GET /code_fetch`：获取验证码/代码相关数据。
- `GET /analyze_image`：图像分析。
- `POST /update_run_status`、`/update_re_status`、`/update_r_status`：状态回传。
- `POST /c_status`：读取/更新拦截状态。
- `POST /img_updata`：图片相关数据上报。
- `GET /orderid_find`：订单号查询。
- `POST /update_order_data`、`/uporderid_status`：订单状态更新。
- `GET /get_coords`：滑块/图像坐标获取。
- `POST /code_upload_batch`：批量上传识别/验证码数据。

**维护建议：** 修改脚本前先确认同机运行的 5000 端口服务接口字段没有变化；否则脚本本身即使找图正常，也可能因任务/状态协议不一致而失败。

仓库中同时将 `.atc` 的内容解包到 `充值2026_Attachment/` 子目录，便于 GitHub/Codex 直接查看、搜索和替换单个素材；完整文件名见自动生成的 `充值2026_附件清单.md`。

### 修改图片资源时

1. 优先在 `.mq` 中搜索图片文件名，确认它被哪个函数/分支使用。
2. 替换截图时尽量保持目标分辨率、裁剪区域、缩放比例和关键视觉特征一致。
3. 同名替换比同时改源码文件名风险更低；若改名，要同步修改 `.mq` 中所有引用。
4. UI 改版后应把旧图保留到确认不再引用，再删除，避免隐藏分支运行时缺图。

## 9. 重要维护风险

- **硬编码设备 ICCID**：换 SIM/换设备后可能直接进入“未知设备”并重启脚本。
- **硬编码活动 URL**：部分 URL 含 2024/旧活动路径，活动下线后分支可能失效。
- **强依赖图片识别**：App/Web UI 视觉改版会导致找图失效。
- **本机后端为单点依赖**：`127.0.0.1:5000` 服务异常时主流程无法正常拿任务/回传。
- **UI 配置存在遗留项**：代码读取的部分 key 在当前 `.uip` 中不存在。
- **编码**：原始按键精灵文件使用 GBK/GB18030 风格编码；直接用某些编辑器强制转 UTF-8 后再导回按键精灵前，应先验证兼容性。

## 10. 文件权威性

- 运行逻辑以 `.mq` 为准。
- 脚本身份/UUID 以 `.prop` 为准。
- UI 布局以 `.uip` 为准，事件以 `.uis` 为准。
- 找图/节点资源以 `.atc` 为打包权威版本；`充值2026_Attachment/` 是为了开发方便展开的镜像目录。
- `.mqb` 是上述内容重新打包后的可导入版本。修改拆包文件后，如需重新导入按键精灵，应由按键精灵手机助手重新打包/导出，避免手工 ZIP 导致格式或编码标志不兼容。
